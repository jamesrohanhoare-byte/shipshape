# Sketch 002: Home Command Centre

## Design Question
Turn Home from a noticeboard into a command centre: surface **tasks due today** + **low stock**
(the two things people open the app for), a **your-week hours** glance, then recent activity.
Which arrangement of the attention/stat cards reads best?

## How to View
open .planning/sketches/002-home-command-centre/index.html

## Variants
- **A: Hero attention** — a single full-width "Needs attention" card with tasks-due and low-stock as big tappable rows; a 2-up "your week" row (worked / slept); then recent activity. Calm, very scannable.
- **B: Tile grid** — a 2×2 grid (tasks due, low stock, worked, slept); alert tiles tinted amber; then recent activity. Denser, everything at once.

## What to Look For
- Does "tasks due today" + "low stock" up top make Home feel actionable?
- A's hero card (calm, fewer numbers) vs B's grid (dense, more glanceable)?
- Where should the financial stat (stock value, when enabled) sit?
- Tap targets: each attention item taps through to its page (Tasks / Shopping / Hours).
